About mission states

Game launch runs the original launcher’s counter preparation, compiler, terrain and option overrides, player equipment generation and handoff writers. The original simulator then loads and constructs that same state.

Campaign examples use the original starting hangar and an explicitly fresh chapter history. Later missions can differ with previous events, equipment and the random sequence. Original recordings and imported saves retain their actual state. State sources and importing an original launch.

The advanced compiler tests retain artificial counter values for diagnosing conditional branches. Source view shows unresolved alternatives without constructing actors. Changing inspection options preserves the camera.
