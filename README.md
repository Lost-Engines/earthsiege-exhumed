# Earthsiege Exhumed

A guided look inside Dynamix’s *Metaltech: Earthsiege*: animated HERCs, mission scenery, original sky rendering, soundtrack comparisons, and illustrated articles on graphics, combat, AI, campaigns, sound and reverse engineering.

**[Visit the site](https://lost-engines.github.io/earthsiege-exhumed/)** · [The investigation](https://lost-engines.github.io/earthsiege-exhumed/story/)

The [engine articles](https://lost-engines.github.io/earthsiege-exhumed/articles/) cover:

- [How Earthsiege draws a frame](https://lost-engines.github.io/earthsiege-exhumed/graphics/)
- [Taking a HERC apart](https://lost-engines.github.io/earthsiege-exhumed/combat/)
- [How the HERCs choose a fight](https://lost-engines.github.io/earthsiege-exhumed/ai/)
- [Building a battlefield](https://lost-engines.github.io/earthsiege-exhumed/campaign/)
- [Checking a reconstruction against the original](https://lost-engines.github.io/earthsiege-exhumed/reconstruction/)
- [Inside Earthsiege's soundtrack](https://lost-engines.github.io/earthsiege-exhumed/music/)

Part of the [Lost Engines Project](https://lostengines.com/), alongside [Darker Discovered](https://lost-engines.github.io/darker-discovered/), [TFX Traced](https://lost-engines.github.io/tfx-traced/) and [Corncob Contemplated](https://lost-engines.github.io/corncob-contemplated/).

The checked-in display snapshot builds independently of the research workspace:

```sh
npm ci
npm run build
npm run check
npm run preview
```

Open `http://127.0.0.1:4178/`. See [MAINTAINING.md](MAINTAINING.md) for snapshot refreshes, browser checks and deployment, and [RIGHTS.md](RIGHTS.md) for original-content attribution and exhibit scope.
